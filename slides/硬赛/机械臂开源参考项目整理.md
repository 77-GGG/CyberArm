## 三、与咱们项目相关的选型建议

咱们项目背景：ESP32-S3 双轮自平衡机器人（FOC 无刷轮、IMU、摄像头、2S 锂电池）。

1. **最贴近的参考**：BROBOT 驭风版（自平衡车体 + 舵机手臂）——机械臂装在自平衡车体上时，重心抬高会直接影响平衡控制，值得先看它怎么做重量和重心分配。
2. **舵机 vs 步进电机**：
   - 桌面级轻负载（夹取小物件、演示动作）：MG996R/MG90S 舵机 + 3D 打印最省事，参考 VR体感机械臂 / noshluk2；
   - 较大负载/精度：同步带 + 步进电机 + 编码器，参考立创 3D打印机械臂。
3. **电源注意**：舵机需要独立供电（5–6V），不能从 ESP32 的 3.3V/5V 引脚直接取电；若沿用 2S 锂电池，需要单独做降压或 DC-DC 电源树。
4. **控制板**：如果做多自由度，可参考 32 路舵机驱动板的设计，或直接用 PCA9685 扩展 PWM 通道。

## 四、可以继续深挖的方向

- 在 OSHWHub 用关键词 `3D打印机械臂`、`桌面机械臂`、`MG996R`、`SCARA` 继续检索
- 在 GitHub 搜 `robot arm 3d print`、`servo arm ESP32`、`SCARA ESP32`、`6DOF arm` 等
- 考虑关节形式：垂直关节（类似人手臂）、SCARA（平面拾取）、并联 Delta（高速轻载）
