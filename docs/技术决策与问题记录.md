## 待解决和待验证问题

| ID | 问题 | 处理办法 | 关闭条件/阶段 |
|---|---|---|---|
| T01 | 轴心、零位、TCP 尚未统一成参数 | 从总装导出，建立方向样本，独立定义 TCP | 多个单轴/组合姿态与 Blender 一致，S0 |
| T02 | 五轴姿态约束尚未计算 | 位置优先/带约束 IK、雅可比秩和奇异区分析 | 可行/无解/求解失败与残差报告，S1 |
| T03 | 边界并非固定空间盒 | 条件空间、扫掠检查、制动余量和禁入区 | 终点合法但路径非法等反例拒绝，S1/S2 |
| T04 | 夹爪闭链不能只导出动画 | 移植连续分支求解，检查奇异点/干涉 | 开度区间对照与碰撞记录，S0/S1 |
| T05 | 负载、支承、倾覆未定版 | 按新几何核算，优先固定/支承与必要减重 | S3 设计筛查、S4 实物记录分别完成 |
| T06 | 模型无碰撞不代表实物无碰撞 | 测回差、装配误差、挠度，收缩范围 | 误差包络/实物限位，S4/S5 |
| T07 | 断电后姿态未知，回中会突动 | 默认失能，工装/人工参考与逐轴标定 | 启动/复位实物测试，S4 |
| T08 | OE 非刹车，无位置/电流/温度反馈 | 停止流程、供电/支承，按需加传感器 | 原理图及停止测试，S3/S4 |
| T09 | 实际 ESP 板型、USB 口与引脚不明 | 板卡阶段读取型号/照片/原理图，固化映射 | USB、电平、波形测试，硬件接入前 |
| T10 | 控制源抢占和重连重放 | 租约、boot_id、去重、STOP 独立通道 | 切换、超时、重启故障注入，S2 |
| T11 | 跨板时钟不能直接比较 | 偏差/误差界、boot_id、观测关联 | 偏差/重启/延迟用例正确拒绝，视觉接入前 |
| T12 | PWM 量化与舵机迟滞影响平滑 | 模拟扰动，实测脉宽/响应，调整限制 | 假设与实测分开记录，S2/S4 |
| T13 | 改模型/场景导致旧动作失效 | 版本绑定，取消旧预览/队列并重验 | 工具/模型/场景变更测试，S1/S2 |
| T14 | 视觉安装尺寸与标定未定 | 暂用可调外置支架，定义坐标和视锥 | 软件视野覆盖、实物标定分别完成 |
| T15 | RoboDK 五轴适配未确认 | 主线后独立实验，不阻塞自研软件 | FK/IK/Driver 适配记录 |

这些问题当前不要求用户立即决定。板型/接线和实物参数到对应阶段再收集，软件可先用明确标识的模拟配置推进。
