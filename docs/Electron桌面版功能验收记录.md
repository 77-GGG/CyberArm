# Electron 桌面版功能验收记录

日期：2026-09-14。分支：release/windows-packaging。

最终结果：开发模式 2/2 桌面测试通过；Windows 独立 EXE 2/2 桌面测试通过（17.5 秒）；原有 Python 测试 6/6、C++ CTest 1/1 通过。以上不包含下述尚未验收的平台和安装升级流程。

## 实现范围

共用 Electron 代码位于 desktop/。桌面窗口加载 simulator/frontend 的同一份生产文件，服务继续使用 cyberarm.server，不复制 API 或算法。model.py 增加资源根目录参数和按平台选择核心库的逻辑；碰撞数据与模型通过同一个根目录读取，默认仍支持原网页版启动方式。

独立应用包含前端、模型、碰撞数据、C++ 核心和完整 PyInstaller 后端目录。Windows 入口为 desktop/dist/win-unpacked/CyberArm Studio.exe，需保留其所在目录的全部文件。

## 已解决的问题

| 问题 | 修复 |
| --- | --- |
| 只检查 /api/state，遗漏实际规划失败 | 在真实 Electron 窗口运行规划和执行，并针对冻结后端重跑同一测试 |
| Windows 规划子进程启动卡住 | 移除阻塞标准输入读取线程，改用父进程句柄监控；冻结入口先调用 freeze_support |
| 打包漏掉运行库或碰撞数据 | 完整复制后端目录，明确复制 collision.npz、GLB、JSON 和目标平台核心库 |
| 前端静态路径与开发版不一致 | 保持 frontend/dist 和 assets/revc 布局，不改网页版服务路由 |
| 退出留下规划进程 | Windows 使用 Job Object 约束后端与规划进程，正常关闭先停止模拟，再清理进程树 |
| 导出只触发网页 Blob 下载，缺乏桌面保存入口 | Electron 配置原生保存对话框，保留原有 JSON 格式和导入校验 |
| 构建中途失败仍可能报告成功 | 构建脚本检查每条命令退出码，失败立即终止 |

## 性能优化后的重新冻结与复核

规划内核提速后，源码改动不会进入已打包的应用，因此本轮重新跑了 PyInstaller 并同步冻结产物。三处 cyberarm-backend.exe 的 SHA-256 一致（2856759D5FA59AF73BD02F5309FD08C3FD126F7E34B4F03E15484D432463FB77，14,864,926 字节）。前端未改，桌面加载的 index.html 与模拟器构建的哈希相同。打包脚本另显式声明 --hidden-import scipy.optimize，因为求解器改为函数内惰性导入后，字节码扫描有可能漏掉它。

另在服务启动时增加两个预热任务：冻结后端里每个规划进程的第一次任务要付一次性 import 与碰撞数据解压，预热把它挪到窗口打开期间，并在后台线程里顺带加载惰性求解器。拆开这段成本后，import planner 从 641 ms 降到 127 ms 的主要来源是 scipy.optimize 的惰性导入（653 ms），而它只在冷种子分支才用得到。

复核方式与结果：本机沙箱无法启动 Electron 图形进程（GPU 进程以 exit_code -1073741515 退出，用户数据目录锁文件也被拒绝访问），因此改为直接启动交付产物中的 desktop/dist/win-unpacked/resources/runtime/backend/cyberarm-backend.exe，按与桌面版相同的环境变量（CYBERARM_PARENT_PID、CYBERARM_RESOURCE_DIR 指向同目录 runtime/simulator）并发 HTTP 请求：

| 项 | 结果 |
| --- | --- |
| 到 ready | 0.61 至 2.01 s（系统缓存热） |
| 关节 8° 预览 | 49 至 82 ms / 25 个检查区间 |
| 关节 30° 预览 | 167 至 180 ms / 92 个检查区间 |
| 可达采样（无方向约束） | 49 至 89 ms / 3500 点 |
| 可达采样（方向 [1,0,0]） | 43 ms / 25 点 |

窗口刚显示就点预览时第一次仍需 0.79 至 0.99 秒（预热与之并发），第二次起在 49 至 75 ms 量级。按 ready 后的时间轴复测，这一秒在 ready 后约 0.8 秒内消失（0.7 s 点击 680 至 986 ms，0.8 s 点击 95 ms），与前端加载首页和 33 MB 模型的时间量级相同，所以正常操作不会再遇到它。远程目标（远离工作空间）会走完整套随机种子，实测 3.3 至 4.0 秒，这是惰性求解器被真正加载并跑完所有种子的成本，属预期。Playwright 的两个桌面用例本轮未能重跑，原因同上（沙箱内 Electron 起不来），需要在有图形会话的环境按原命令复核；这不改变用例本身。
