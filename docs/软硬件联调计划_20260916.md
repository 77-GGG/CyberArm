# CyberArm 软硬件联调计划

## 1. 联调目标

按阶段证明以下事项，而不是一次性让整机运动：

1. ESP32-S3、PCA9685、舵机电源和 USB 通信接线正确。
2. 六个通道能单独输出、单独断开，并具有安全的脉宽范围。
3. 每个舵机的机械零位、方向和有效行程与上位机模型一致。
4. 手动控制、规划轨迹、暂停、停止、失联和重新连接行为符合预期。
5. 空载、逐步加负载和长时间运行时不发生撞限位、过热、掉压或复位。

当前普通三线 PWM 舵机没有角度反馈。`commanded_q_deg` 表示固件发出的指令角，不能证明实体已经准确到达。角度误差必须用量角器、标记线或外置传感器测量。

## 2. 全程安全规则

- 舵机使用独立额定电源，不能由 ESP32-S3 的 3.3 V 引脚供电。
- ESP32-S3、PCA9685 和舵机电源负极必须共地；通电前用万用表检查极性和短路。
- 舵机电源串联合适的保险丝，调试时使用限流电源；实体断电开关始终放在手边。
- 首次动作必须拆下舵盘或断开传动。安装机械臂后，必须先支撑所有可能下坠的连杆。
- 未完成六路逐轴标定前，不执行 `hwarm`，不同时驱动六个舵机。
- 出现撞限位、持续嗡鸣、异常发热、焦味、导线变热、电源掉压或 ESP32 复位时，立即切断舵机 V+。
- 软件的 `stop`、`hwdisarm` 和通信看门狗不能代替实体断电。带载失联时固件会保留最后 PWM，避免机械臂立即坠落。

## 3. 调试前准备

### 工具

- 万用表、可调限流电源或带电流显示的额定电源。
- 保险丝、实体电源开关、合适线径的电源线和可靠接头。
- USB 数据线、螺丝刀、备用舵盘和紧固件。
- 量角器或打印角度标尺、记号笔、游标卡尺。
- 支撑机械臂的木块、泡棉或支架。
- 有条件时准备示波器或逻辑分析仪，用于检查 I2C 和 PWM。

|---|---:|---|---:|---:|---:|---|---:|---:|---:|---|
| J1 | PWM0 |  |  |  |  |  |  |  |  |  |
| J2 | PWM1 |  |  |  |  |  |  |  |  |  |
| J3 | PWM2 |  |  |  |  |  |  |  |  |  |
| J4 | PWM3 |  |  |  |  |  |  |  |  |  |

另行记录电源额定电压、电流上限、空载电流、单轴运动峰值电流、六轴保持电流和最低母线电压。

## 4. 分阶段执行计划

### 阶段 A：不上电的机械与电气检查

1. 不接舵机 V+，检查所有打印件去毛刺、孔位、轴承、螺钉和连杆是否能自由活动。
2. 手动缓慢摆动每个关节，确认机械限位和线束不会被夹住或拉紧。
3. 核对 PCA9685：VCC 接 3.3 V 逻辑电源，V+ 接独立舵机电源，地址为 `0x40`。
4. 核对 ESP32-S3 默认 I2C：GPIO8 为 SDA、GPIO9 为 SCL。若实板不同，先修改 `platformio.ini`。
5. 检查所有 GND 共地、V+ 极性、接头压接和保险丝。

**通过标准：** 无短路，机构可以手动通过计划工作范围，线束有余量，舵机 V+ 尚未接通。

### 阶段 B：烧录与无舵机通信测试

1. 保持舵机 V+ 断开，编译并烧录：

   ```powershell
   C:\Users\你的用户名\.platformio\penv\Scripts\platformio.exe run
   C:\Users\你的用户名\.platformio\penv\Scripts\platformio.exe run --target upload --upload-port COM5
   ```

2. 启动上位机，在控制台执行：

   ```text
   hwports
   hwconnect COM5
   hwstatus
   ```

3. 检查 `driver_ready=true`、`outputs_enabled=false`、模式为 `DISARMED`。
4. 使用 `hwdisconnect` 断开，再重新连接，重复三次，确认仅连接不会产生 PWM 输出。

**通过标准：** 串口稳定出现，固件能应答，PCA9685 被识别，连接过程不会使舵机通道输出。

### 阶段 C：台架单舵机回中

六个舵机逐个执行，本阶段不要连接机械传动：

1. 拆下舵盘，PCA9685 只接一个舵机，电源先设置合理限流。
2. 保存保守的初始脉宽，例如 J1：

   ```text
   hwcal 1 1300 1500 1700 false
   ```

3. 确认舵机可以自由转动后执行：

   ```text
   hwcenter 1 SUPPORTED
   ```

4. 观察舵机是否平稳到达中位，记录电流、噪声和温升，然后执行 `hwdisarm`。
5. 对 J1 至 J5 和夹爪 G 重复。控制台轴编号为 1–6，对应 PCA9685 PWM0–PWM5。

**通过标准：** 每个舵机都能单独回中、单独关闭，无剧烈跳动、持续嗡鸣、异常升温或 ESP32 复位。

### 阶段 D：安装舵盘并建立机械零位

每次只处理一个轴：

1. 支撑相关连杆，让舵机不承担意外负载。
2. 使用 `hwcenter N SUPPORTED` 让舵机保持已标定的中位。
3. 把舵盘以最接近模型零位的齿位安装，先临时拧紧。
4. 执行 `hwdisarm` 后微调 `center_us`，再次回中确认；不要带电拆装舵盘。
5. 以小步长测试方向。方向相反时先关闭输出，再把 `reversed` 改为 `true`。

模型当前把 J1–J5 定义为 ±30°、夹爪定义为 ±8°。`min_us/center_us/max_us` 对应模型负限位、0°和正限位，并不对应舵机完整的 0°/90°/180°。

**通过标准：** 指令 0° 对应机械零位，小幅正负命令方向正确，零位重复三次后没有明显漂移。

### 阶段 E：逐轴测定安全脉宽和机械行程

1. 从保守范围 `1300/1500/1700 μs` 开始，每次只改变约 5–10 μs。
2. 每移动一步，检查机构间隙、舵机声音、电流和温度。
3. 在触及机械限位、明显吃力或电流快速上升之前停止，并留出安全余量。
4. 用量角器记录模型负限位、零位和正限位的实际输出轴角度。
5. 保存最终脉宽和方向，断电重启后确认 NVS 中的校准仍然存在。

**通过标准：** 六路均已确认，任何允许指令都不会碰撞机械限位，断电重启后校准不丢失。

### 阶段 F：整机小范围手动联动

1. 空载、充分支撑机械臂，把上位机仿真姿态设为装配零位。
2. 执行：

   ```text
   hwstatus
   hwarm SUPPORTED
   ```

3. 每次只动一个关节，从 ±1° 开始，逐步扩大到 ±2°、±5°。
4. 对照仿真模型和实体的运动方向、起止时间以及大致角度。
5. 每个动作后检查 `hwstatus`；结束时执行 `hwdisarm`。

**通过标准：** 六轴都能与仿真同方向运动，其他轴没有异常抖动，USB 通信、供电和 ESP32 均保持稳定。

### 阶段 G：规划轨迹、暂停和停止

1. 先使用很慢的速度和较小的关节范围创建一段两点轨迹。
2. 在上位机预览通过后执行，确认实体和仿真同时启动、同时结束。
3. 分别测试 `pause`、`resume`、`stop` 和重新使能。
4. 在机械臂被支撑且无碰撞风险时，测试拔掉 USB：固件应在约 1.5 秒后进入 `FAULT`，带载模式保持最后 PWM；恢复通信后必须重新连接并显式使能。
5. 测试单轴中位服务模式失联：超时后该通道应关闭 PWM。

**通过标准：** 轨迹不出现明显顿挫；暂停、停止、失联和重新连接后的状态与上位机显示一致；故障后不会自行恢复运动。

### 阶段 H：逐步加载与电源验证

1. 先空载运行，再逐步安装末端零件和计划载荷；每增加一次负载都重复小范围测试。
2. 重点观察 J2、J3 等承重轴，以及底座电源线和公共接头。
3. 记录启动峰值电流、保持电流和最低电压；检查是否出现棕断复位、USB 断连或 PCA9685 异常。
4. 连续执行低速安全轨迹 20 次，之后运行 30 分钟，定期记录舵机、电源和接头温度。
5. 出现负载下角度偏差时，先检查结构变形、舵盘间隙和供电，不要直接扩大脉宽范围补偿。

**通过标准：** 预期负载下连续运行无复位、无过热、无松动、无撞限位，电源和线束留有余量。

## 5. 推荐日程

| 时间 | 工作 | 完成条件 |
|---|---|---|
| 第 1 天 | 阶段 A–B：机械、电气、烧录和通信 | 无舵机供电时通信与驱动板稳定 |
| 第 2 天 | 阶段 C：六个舵机台架回中 | 六路单独输出和关闭均正常 |
| 第 3 天 | 阶段 D–E：舵盘安装与逐轴标定 | 六路零位、方向和安全范围有记录 |
| 第 4 天 | 阶段 F：整机小范围联动 | 仿真与实体六轴方向一致 |
| 第 5 天 | 阶段 G：轨迹和故障行为 | 执行、暂停、停止、失联均通过 |
| 第 6 天以后 | 阶段 H：载荷和耐久 | 预期负载连续运行通过 |

不要为了赶日程跨过阶段。任何阶段失败，都回到上一阶段排除问题。

## 6. 常见故障定位顺序

| 现象 | 优先检查 |
|---|---|
| 找不到串口 | USB 线是否支持数据、使用的 USB 口、驱动、烧录口与 CDC 口是否相同 |
| `driver_ready=false` | PCA9685 VCC/GND、GPIO8/9、I2C 地址、焊接和共地 |
| 舵机完全不动 | V+ 是否上电、通道映射、是否已校准、`outputs_enabled`、接头方向 |
| 舵机方向相反 | 关闭输出后修改该轴 `reversed`，不要交换电源线 |
| 舵机抖动或 ESP32 重启 | 电源电流不足、压降、共地不良、接头松动、信号线受干扰 |
| 中位偏差大 | 舵盘齿位、`center_us`、机构装配误差；普通舵机无法读取实际角度 |
| 到端点嗡鸣发热 | 脉宽范围过宽或机械干涉，立即断电并收窄范围 |
| 仿真动、实体不动 | `hwstatus` 中的连接、校准、使能、模式和故障状态 |
| 轨迹中途进入 `FAULT` | 心跳/USB 中断、电源复位、上位机进程状态和串口占用 |

## 7. 整体验收清单

- [ ] 六路通道映射和线束标签完成。
- [ ] 六路 `min_us/center_us/max_us/reversed` 已记录并重启验证。
- [ ] 六路零位、方向和安全机械范围正确。
- [ ] 上位机手动小范围控制与实体方向一致。
- [ ] 规划轨迹的启动、运行和结束与仿真基本同步。
- [ ] 暂停、停止、断连、看门狗和重新使能已验证。
- [ ] 空载与计划载荷下的电流、电压和温度已记录。
- [ ] 连续循环和 30 分钟运行无复位、过热、松动或撞限位。
- [ ] 已记录普通 PWM 舵机没有真实角度反馈这一限制。

完成以上项目后，再开始接入 K230D。K230D 初期只发送带时间戳、置信度和坐标系的检测结果，不直接控制 PWM；视觉目标仍应经过上位机的坐标变换、逆解、碰撞检查和轨迹执行链路。
