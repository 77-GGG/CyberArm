# CyberArm 上位机界面与功能说明

日期：2026-09-14。分支：features/simulator。状态：交互设计，尚非完整可运行界面。

## 参考与还原范围

参考作者的 [Dummy DLC-上位机演示](https://www.bilibili.com/video/BV1b44y1x7JH/) 与 [项目说明](https://github.com/peng-zhihui/Dummy-Robot#关于上位机)。本次在浏览器观察官方演示约 00:17 与 01:02 画面：深蓝灰三维网格场景占主窗口；关节手动面板悬浮在右下角，包含 J1–J6 数值、滑条、复位及末端位置；右上为视角指示器；串口调试窗口可覆盖三维场景。作者说明自研软件增加了实时同步，后续计划相机标定、手眼标定和 GCode 等扩展，不能把这些计划认定为已完成模块。

本项目还原上述视觉布局和直接操控体验，使用自己的 RevC 模型、图标和软件实现。动作编排、条件可达显示、路径检查是本项目设计，未据此声称官方演示具有同样功能。现有五轴结构无法复制六轴机械臂的任意末端姿态能力。

## 主窗口

- 三维场景占据绝大部分窗口：深蓝灰背景、透视网格、柔和阴影；显示 RevC 实际模型，支持旋转、平移、缩放和前/侧/顶视图。
- 左上放轻量工具栏：项目、操作模式、场景、显示和设置。始终可见“模拟模式”。
- 右上放视角指示器及简洁运行状态。
- 右下放悬浮控制卡片，切换“关节 / 末端”。关节页为五个运动轴加独立夹爪开度，不能将夹爪标成第六姿态轴。包含数值、滑条、点动、速度和回参考位。
- 底部动作面板默认收起，展开后显示关键帧列表、等待/夹爪步骤、时间线和播放进度。暂停、继续、停止在执行期间保持可见。
- 工作空间、碰撞体、坐标系、轨迹、调试日志按需显示，默认不遮住机械臂。

## 计划功能与交互

| 功能 | 用户操作与反馈 |
|---|---|
| 关节手动 | 调节五轴角度与夹爪；点动和键盘输入统一经过限制与运动检查 |
| 末端操控 | 拖动目标坐标轴或输入 XYZ；可选择位置优先或可支持的方向约束，显示误差及求解状态 |
| 目标预览 | 目标分身与当前机械臂分开；检查通过才执行，过期计划重新检查 |
| 条件可达范围 | 按模型限位、工具和姿态条件显示采样区域；采样仅供观察，执行仍需独立验证 |
| 路径与边界 | 预览关节运动 MoveJ、直线运动 MoveL；检查路径及停止过程，指出越界或干涉对象 |
| 动作编排 | 保存姿态、夹爪动作、等待时间、有限循环，预览、回放、暂停、继续、停止 |
| 场景编辑 | 添加简单障碍物，调整位置尺寸，保存场景；修改后旧动作重新验证 |
| 文件与脚本 | 导入导出场景和动作；Python SDK 使用与界面相同的控制入口 |

预览颜色辅以文字：通过、超限、碰撞、姿态不满足、求解失败，不能仅以一个红色目标混淆原因。“求解失败”不宣称数学上绝对不可达。回参考位也需验证路径；停止按钮表示模拟控制器停止，不冒充物理急停。

典型流程：拖动末端目标 → 查看目标分身及检查结果 → 预览路径 → 执行 → 保存关键帧 → 组合动作 → 回放。

## 当前实现状态

已创建本地开发环境、导出 RevC GLB 与 67 组参考姿态、实现 C++ 正运动学/夹爪联动及 Python 调用。基础 CTest 已通过，已有参考矩阵数值对照；这不等于完整功能验收。

完整界面、逆运动学、碰撞与路径验证、动作编辑和 SDK 尚未完成。TCP 仍是待核验的模拟定义，关节范围仍为模型预览限制，不是实测舵机范围。当前无硬件双向同步，也不做视觉模块；先完成可验证的纯软件仿真。
