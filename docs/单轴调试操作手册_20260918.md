# 单轴调试操作手册

适用：本次重构后的上位机源码。入口为 **调试 → 实机调试 → 单轴标定**。单轴标定兼容固件 0.3.0；在界面修改模型软限位需要升级到固件 **0.4.0**。烧录一次后，日常修改软限位无需重新编译。

## 先理解三个角度

| 名称 | 含义 | 如何获得 |
|---|---|---|
| 舵机标称 180° | 产品标称行程，不定义机械臂安装后的关节零位 | 查对应型号资料，再实测可用行程 |
| 关节角 | 相邻连杆相对于机械设计零位的转角，有正负方向 | 对齐机械参考，用量具读数 |
| 指令角 | 根据保存的映射换算为脉宽的目标 | 软件计算；不代表已经到达的实体位置 |

1500 μs 是常用的中位指令起点，不保证正好位于当前舵机行程正中，也不自动等于机械臂关节 0°。普通三线舵机内部虽有位置控制，当前接线没有将其位置反馈给 ESP32，所以真实关节角显示为“—”。脉宽稳定也不代表实体已到位。

## 第一次调试一个关节

准备外部量具、关节零位参考，并支撑相关连杆。每次只调一个关节，其他通道不输出。对于尚未确定舵盘安装关系的舵机，先断开传动确认方向和可用位置，再完成安装对齐，不强扭带输出的舵盘。

### 1. 准备输出

1. 在“连接与安全”连接 ESP32，确认 PWM 驱动就绪，再进入“单轴标定”。
2. 选择 J1/J2/J3/J4/J5/G，核对界面显示的 PCA9685 通道与实际接线。通道编号从 0 开始。
3. 首次使用窄窗口：默认下限 1400 μs、初始 1500 μs、上限 1600 μs，变化速度 50 μs/s。需先核对这些值适合自己的舵机；它们只是测试起点。
4. 勾选“已断开传动或支撑机构，确认第一帧脉宽”，点击“开启选中舵机”。界面自动进入“确定零位”。

首次输出会直接建立一个位置指令，软件不知道原来的实体位置，不能保证首次上电无跳动。之后的点动受脉宽变化速度限制。

顶部始终保留关节、PWM 状态和停止按钮。输出开启时不能换轴或修改窗口。

### 2. 确定零位

1. 用 ±1 计数细调，±5 计数作稍大的点动。计数是 PCA9685 的输出单位，不是角度。
2. 观察正负点动时的真实旋转方向，按下方三维参考中的本轴 +5° 确定正角方向。
3. 查看找零页的“查看全零姿态”，对照相邻结构的模型装配关系。等实体稳定后，用量具对齐零位，再点“记录当前位置为关节 0°”。
4. 进入“下一步：采集角度”。没有零位记录时，采集角度步骤不会开放。

如果需要改变已装舵盘的齿位，先关闭输出并按机械装配要求处理。不要把舵机外壳的某条边或脉宽 1500 μs 自动视为关节零位。重做零位后，已有两侧读数也应重新复核。

### 3. 采集角度

1. 从零位向一侧小步移动，等实体稳定后，用量具测相邻连杆的相对角度。
2. 填“人工角度读数”，选择正向/反向接近，填写负载或备注，再点“记录人工测量”。
3. 回到另一侧，至少再记录一个异号角度。最少是负角、0°、正角共三个点，最多七个点。
4. 需要更大使用范围时继续小步探索，在较远处补采点。误差明显的区段可增加中间采样点。

同一个角度的再次记录会替换该标定点；原人工记录仍在记录详情里。角度升序排列后，脉宽应始终增加或始终减少。正反映射均支持，不需要再额外勾选“反转”。如果脉宽方向不一致，界面会提示检查测量值、接近方向和重复点。

**到脉宽窗口边界时：** 先关闭输出 → 返回“准备输出” → 少量扩大一侧窗口 → 检查初始脉宽 → 重新勾选并开启 → 返回采样步骤。上一次测量草稿会保留。500–2500 μs 只是软件允许的参数边界，不是所有舵机都能承受的安全行程。

不要自动扫描到硬挡块，也不要通过持续顶住来确认“最大角”。发现干涉、异常持续噪声或实体不再随指令移动时立即停止，不再向外推进。

### 4. 限位与保存

填入已经实测验证、且相对可用边界留有余量的工作下限和上限。当前标定格式要求下限 < 0° < 上限，范围必须被采样点覆盖。

界面分别显示四行：

| 范围 | 含义 |
|---|---|
| 模型配置限位（软件参数） | 仿真/规划所使用的配置范围，不是舵机物理行程 |
| 实测标定覆盖 | 最小和最大采样角度之间的范围 |
| 本次工作限位 | 本次准备保存的工作范围 |
| 保存后整机有效范围 | 上面三者的交集 |

例如：模型 ±30°，实测覆盖 −25°～+28°，确认工作范围 −20°～+22°，则整机有效范围是 −20°～+22°。缩小范围不会重新缩放角度，原来 10° 对应的脉宽保持不变。

保存顺序：

1. 点击顶部“关闭输出”。
2. 排除页面列出的数据问题，人工复核零位、方向、量具读数和范围。
3. 勾选“这些点为当前设备人工实测，方向、零位及范围已复核”。
4. 点击“确认保存到 ESP32 并读回”。看到“读回一致”后，再进入验证。

更改草稿会撤销实测确认，需要重新勾选。点动和采样只改草稿，正式保存才写设备 NVS。保存后的整机有效范围用于实机跟随；连接设备但未使能时，纯仿真使用设备回报的模型软限位。断开设备后恢复随软件打包的默认模型范围；设备中的参数不会被清除。

### 5. 验证角度

1. 重新确认支撑条件并开启单轴输出。界面显示即将发送的第一帧脉宽和测试窗口。
2. 输入接近当前姿态的目标角，点击“按已保存标定试转”。使用的是设备保存值，不是未保存草稿。
3. 等实体稳定，用量具读数，再点击“记录人工测量”。
4. 换几个目标，分别从正向和反向接近，比较误差和重复性。还要在实际负载下复核。

如果目标超出设备有效范围、当前测试窗口或 100 μs 单次变化限制，界面会指出原因；选择更近的目标分步接近。软件不会自动分段连续扫动。

只有实际发送目标后才允许记录该目标的验证结果。修改目标、暂停脉宽变化、关闭输出后，需要重新发送目标。统计只计入当前设备标定版本的验证记录；旧版本记录保留在详情中，不混入新版本最大误差。老版本没有版本编号的历史验证记录也只保留在详情中。

没有统一适用于所有关节的合格误差阈值，应按机械臂任务要求判断。误差大时重新核对量具参考、零位、方向、负载、齿隙，再补采点或缩小工作范围。

完成一轴后保存电脑草稿或导出记录，关闭输出，再切换下一轴。切轴会保存当前草稿。直接关闭调试页会结束输出，但未主动保存的最新草稿不保证保留。

## 每个关节的 0° 从哪里开始？

当前模型的 0° 是 CAD 导出时的原始装配姿态，即六个关节增量都为零。它不等于舵机中位，也不等于每段连杆水平、竖直或全部伸直。

| 关节 | 0° 的相对参考 |
|---|---|
| J1 底座回转 | 上部转台相对固定底座的原始装配朝向 |
| J2 肩俯仰 | 大臂相对底座转台的原始装配姿态 |
| J3 肘俯仰 | 小臂相对大臂的原始装配夹角 |
| J4 腕旋转 | 腕部相对小臂的原始安装朝向 |
| J5 腕俯仰 | 夹爪安装座相对腕部的原始安装姿态 |
| G 夹爪 | 两侧齿轮、连杆的原始装配状态，非完全闭合/0 mm 开口 |

“确定零位”页提供独立三维视图，可旋转查看并切换顶视、前视、侧视。按“查看全零姿态”看参考装配，按“查看本轴 +5°”看正方向，其他轴保持零位。蓝色箭头标出该轴正向，转角按右手定则定义；不要从屏幕上的顺/逆时针猜方向。参考查看只做运动学计算，不改变当前仿真姿态，也不发送任何舵机指令。

这些参考来自 `robot.json` 的 `joint_local` / `zero_frames` 和运动学核心；J1–J5 以各自局部 Z 轴作旋转轴。全零姿态下，J1 正轴近似基座 +Z，J2/J3/J5 近似基座 +Y，J4 约为基座方向向量 (0.788, 0, −0.616)。G 是闭环驱动角，核心在左齿轮 −155°、右齿轮 +147.5° 的装配基角上分别加减 G；这两个基角不是舵机电气角度。

实体仍需选择可重复识别的安装特征或做零位标记。推荐在固定件与活动件上设对应刻线，拍照并记录量具基准。当前模型没有替你定义某个实体孔位/外壳边缘的可量化校准基准，因此必须先核对实物与模型的装配关系；软件不能自动判断是否对齐。机械结构或装配参考改变时，需要重新复核标定。

## 能否测到舵机最大角度？

可以人工确认“当前安装和负载条件下已经验证可用的两端角度”，不能靠当前硬件自动判断绝对机械极限。角度不再变化也可能来自干涉、负载、供电或舵机自身限制，软件无法区分。

推荐分别记录：舵机脱离机构时的可用行程、装入机械臂后的无干涉行程、留余量后的工作范围。实际采用三者中更保守的范围。余量应由负载、回差、装配误差和重复测试结果决定，不能把刚好顶住的位置作为工作端点。

标称 180° 不保证当前装配能使用完整 180°；机械零位也可能使两侧可用角度不对称，例如 −65°～+90°。若机械臂多关节组合产生碰撞，单关节范围本身并不能排除组合姿态的碰撞，仍需低速整机验证和碰撞检查。

脉宽与转角、端点的关系需要按具体舵机确认，参考制造商控制说明：[Pololu：舵机控制接口详解](https://www.pololu.com/blog/17/servo-control-interface-in-detail)。

## 软件里的关节限位怎么改？

**日常调整工作限位：** 在底部展开“草稿、备份与设备数据”，先保存或导出要保留的草稿，再点“用设备值替换草稿”，进入“限位与保存”。可以直接收紧范围；放宽时，新增部分必须已验证且在采样覆盖内，否则先补采点。关闭输出、重新确认、保存并读回后生效。

**扩大模型软限位：** 在工作台下方展开“修改模型软限位参数”。默认的 J1–J5 ±30°、G ±8° 是暂定软件参数，不是模型几何或舵机的物理最大行程。

1. 烧录 0.4.0 固件并重新连接，关闭所有输出和整机运动。
2. 选中关节，输入新的模型下限、上限。例如经结构核对后，可以把 J1 改为 −75°～+80°。
3. 勾选结构核对确认，点击“保存模型软限位并同步”。
4. 读回一致后，上位机在连接期间使用设备保存值，关节滑条、逆解、路径规划、控制台与固件校验使用对应的新范围。
5. 再采集覆盖实际使用范围的角度点，保存工作限位。仅扩大模型参数，不会自动扩大实测工作范围。

参数允许 −180° ≤ 下限 < 0° < 上限 ≤ 180°；这是软件参数上界，不表示舵机有 360° 行程。夹爪 G 额外检查连杆闭环的连续区间，经过无解或奇异位置时拒绝保存；即使几何有解，也还需核对实体干涉与实际负载。

如果当前仿真角度不在拟缩小的范围内，保存会被拒绝。先保持实机输出关闭，在仅仿真模式把该轴移回范围内，再保存。

参数逐轴存入 ESP32 NVS，绑定模型和接线摘要，每次保存递增版本并读回。电脑 JSON 记录同步备份 `model_limits_deg` 与 `limits_revisions`，备份写失败会提示，控制以设备回读为准。接线摘要变化后重新使用默认参数并复核。旧 0.3.0 固件没有这个能力，界面不假装修改成功。

[robot.json](../simulator/assets/revc/robot.json) 与 [FirmwareConfig.h](../lib/CyberArmFirmware/src/FirmwareConfig.h) 的原始范围现在作为未配置时的默认值；正常调试不必手动修改它们。导入电脑草稿不自动覆盖设备软限位。

若硬件零位只能处在行程端点，导致可用关节角只有正数或只有负数，当前要求零位两侧都有标定点的格式不适用；需要另行调整模型角度定义和标定协议，不能编造异号测量点。

## 常见情况

| 现象 | 处理 |
|---|---|
| 开启按钮不可点 | 检查 PWM 驱动、整机是否仍使能、输出占用、测试窗口和支撑确认 |
| 下一步不可点 | 按当前页缺项提示补零位、两侧采样点或正式保存 |
| 点动按钮到边界禁用 | 关闭输出，在准备页少量扩展窗口；不要跳到最大边界 |
| 保存按钮不可点 | 关闭输出，修正范围/测量点，再勾选人工实测确认 |
| 角度验证仍不可记录 | 先发送目标并等待脉宽稳定，再填写外部量具读数 |
| 设备值与电脑草稿不同 | 运动始终使用设备值；载入设备值前先导出要保留的草稿 |
| 页面意外关闭或调试通信中断 | 单轴租约停止续约后，固件约 1200 ms 内关闭输出；重新打开页面不会自动恢复输出 |
| 按“暂停脉宽变化”仍有力矩 | 它只是冻结脉宽目标，PWM 仍开启；“关闭输出”才关闭 PWM，但不提供机械锁止 |

本次软件测试不代替实体接线、负载、PWM 波形及角度精度验收。接线 JSON 和编译说明见 [单轴标定与 JSON 接线使用说明](单轴标定与JSON接线使用说明_20260917.md)。
