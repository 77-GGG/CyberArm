## 控制逻辑

### 手动控制：路径预览默认关闭

调整关节角度、夹爪或末端坐标后，直接更新当前仿真姿态。场景实体、当前 TCP 和控制器状态来自同一个后端状态，不需要先点击“预览路径”或“执行”。末端仍可通过 X/Y/Z 轴与平面手柄拖动。

`POST /api/manual` 根据当前关节状态求解目标，检查限位、姿态干涉和连接段。有效更新写入控制器，递增执行序号，令旧计划失效；不生成供用户确认的路径计划。无解或连接段不通过时保持当前位置并说明原因。停止、场景修改、自动执行和并发状态变化会拒绝未完成的旧请求。

手动模式不是实机在线控制；仓库仍然运行原有本地模拟器。手动更新直接改变仿真姿态，自动执行则沿速度和加速度约束下的轨迹运行。

### 可选路径预览

在手动模式显式勾选“路径预览”，进入目标编辑流程：调整目标、检查路径、执行。主实体仍显示当前状态，规划终点使用半透明模型表示。关闭后清除规划显示并同步当前位置，恢复手动实时调整。

示教和自动模式默认开启路径显示，保留目标编辑、逆运动学、方向约束、MoveL、路径检查、速度设置、保存目标、等待、循环、排序、删除、整组预览及执行。隐藏路径显示不删除动作序列。

“记录当前姿态”在手动模式保存当前仿真关节；“保存当前目标”在示教或自动模式保存编辑的目标。模式切换不清空动作序列。

## 界面

采用用户选择的浅色工业工作台风格：白灰底色、蓝色强调。顶部为模式与项目工具，中央为独立三维视图，右侧固定控制区，底部集中显示状态、暂停、继续、停止和日志入口。

坐标、误差和关节数值按区域分组。方向与运动选项默认折叠；模型细节、限位来源、网格说明和快捷键集中放在设置中。项目、场景和动作序列使用可关闭面板。小窗口下内容区滚动，主要操作及停止按钮保持可见。

```powershell
cd desktop
npm run build:workbench
$env:CYBERARM_TEST_EXECUTABLE=(Resolve-Path 'dist/workbench/win-unpacked/CyberArm Studio.exe').Path
npm test
```

运行时须保留完整 `win-unpacked` 目录。
